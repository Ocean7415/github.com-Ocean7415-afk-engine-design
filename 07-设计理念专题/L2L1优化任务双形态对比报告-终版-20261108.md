# 双形态对比报告终版 · L2 pi agent 核心 vs L1 内嵌车道（MeetingCopilot 混合检索任务 · run13-17 五轮实证 · 2026-11-08）

> **一句话**：同一任务（MeetingCopilot 检索内核：纯 BM25 → 混合检索 BM25+向量+RRF）·同一冻结契约（OPT-ACCEPTANCE v2）·同一冻结考题（12 例 top7+19 例回归）·同一模型（glm-5.3）——**pi agent 核心承载的 L2 形态 332,296 tokens 一轮交付+维修段全绿；内嵌 llm.ts 车道承载的 L1 形态五轮 1,193,529 tokens 四种形态逐轮跳变未收敛**。归因主因=迭代闭环结构差异（连续会话精修 vs 无状态重抽），治法=岗位 pi 化转正（L2 形态产品化+十岗位任务档迁移）。

## 三、归因五层（为什么差 3.6 倍 token 且未收敛）

| 层 | 归因 | 实锚 |
|---|---|---|
| ① **迭代闭环结构（主因）** | L2=同一 pi 会话内多循环自验精修（上下文连续）；L1=无状态单次重写（每次调用全新 prompt·每轮从零换实现策略） | 四轮四套实现策略（140→79→170→160 行逐轮换） |
| ② 缓存经济 | L2 前缀稳定→cacheRead 7.69M（重复上下文≈1/10 价）；L1 回喂盒变化→指纹命中 0%（每次全价）·单调用密度 13.2k vs 4.5k（差 3 倍） | 晨报 §三 |
| ③ 自验深度 | L2 自验期暴露并修掉并发争抢（51.3s→10.5s·单飞锁+线程帽）；L1 四轮死在语法门/挂死——**从未触达深层** | L2-done §三.7 |
| ④ 域难度 | 同步桥+本地 ONNX 推理+worker 通信=高难新域（对两者同等难·消化方式不同） | 五轮五病 |
| ⑤ L1 的钱买了什么 | 形态库 +6 实锚+机制验证全套+对照实验组数据——**实验资产非交付物** | 判卷存证族 |
