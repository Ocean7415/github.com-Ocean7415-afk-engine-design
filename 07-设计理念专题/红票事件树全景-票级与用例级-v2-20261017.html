结论先行（三条）：

① 票层级「红票」= 施工红 / 对题红 / 回喂重写红 / 硬化红 / 连坐红 / 车道异常红 / 翻案红 七源同出口——全部经 makeRedRuling 走 R05 停车场：red → park#1 → 补考一轮 → park#2=final（DEF 晨报追认）；唯一例外=篡改红旗（fail-closed 终局，不进⟲环不进降级链）。

② 用例层级「红」不判票死：探针红只入账（红≥2 开缺陷单·R15 streak 立 DEF），自愈⟲1 → 坐席B 升级 → 补票环三闸，未消=整单 PASS\* 带星追认；切片①功能红=硬化挂起（宁停不烧变异）；切片②红=回归翻案⟲1（吊销已绿灯重挣）或整单 FAIL。

③ 两层红绿权威同源=验收命令 exit code（#28②）；任何机制「扣绿不加红」——机械设备管判卷与守卫，Agent员工只管修复，自然人审核只出现在 final/追认/翻案清单。
