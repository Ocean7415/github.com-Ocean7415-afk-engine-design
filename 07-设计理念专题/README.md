## 权威与版本纪律（本区特有·沿 v1.2 拍板#35）

1. **html 为成品权威**：改理念/口径 = 直改 html 对应节 → 页尾「版本与变更记录」append 加行、版本号递增。**不做「md 正本→渲染 html」**。
2. **引用不复制**：拍板原文在 `90-过程/拍板记录表.md`、对比件在 `90-过程/handoffs/`、v1.2 权威区两件（`../langgraph-v1.2/07-设计理念专题/`）**只读引用**（本仓红线 2）——本区只写结论 + 编号锚点，不搬运正文。
3. **教训内建**：本区 html 自带页头版本行 + 页尾 append-only 变更记录。
4. **视觉风格**：单文件、无外链、双击即读（沿 v1.2 07-设计理念专题 同款）。
