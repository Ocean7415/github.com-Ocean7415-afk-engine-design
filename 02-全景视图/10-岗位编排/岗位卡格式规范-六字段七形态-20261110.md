# 岗位卡格式规范 · 九字段×七形态（pi 时代新岗卡母版·含 skill_工具与 RAG 分配）

> **适用**：pi 会话窗道全部新岗（施工窗/调研窗/核验员 4b/精修窗/对题审查轻窗/班间维修员/路由员/值守窗班/主窗主持人）。
> **不适用**：零 LLM 机械件（机制非岗·入 13-闸口清单册）·夜车 niche 内嵌岗（退役归档·原 18 卡格式不变）。
> **纪律沿袭**：七形态=岗卡 README 裁剪版（拍板#28）·frontmatter 六字段=一层链一级标注（业主令 2026-11-10）·规格视图不复制提示词（拍板#211 先例·pi 窗岗提示词事实源=任务书/SOP 卡）。

## §一 frontmatter 字段规范（逐字段·必填标 ★）

| 字段 | 必填 | 取值 | 说明 |
|---|---|---|---|
| id ★ | ✅ | 册内序号 | 会窗-NNN（会话窗册）／轻窗-NNN（轻窗册）／规划-NNN／夜车-NNN（niche 封存） |
| name ★ | ✅ | 岗名 | 例：施工窗 agent／核验员 4b |
| kind ★ | ✅ | employee｜station | station=编排工位·零模型调用 |
| **类别** ★ | ✅ | **pi全窗｜pi轻窗｜零LLM机械** | 一级分类（业主令 2026-11-10 三分类） |
| **车道** ★ | ✅ | **pi会话窗道｜内嵌chat车道（niche封存）｜—（机械）** | 内嵌当前封存（拍板2 修订·解封条件留档） |
| **账面** ★ | ✅ | **L1 工序票（PKG 切片·票级账）｜L2 窗票（W-NNN·窗级账）｜班次账｜资产（无票）｜规划段（无票）｜横切（跨账）** | 一级标注·双名制（拍板#534①） |
| **对应票** ★ | ✅ | 窗口票 W-NNN｜PKG-NNN 切片｜维修票｜— | 主账面＋兼注（双名括注） |
| **班属** ★ | ✅ | 班内｜班间｜班外｜跨班常驻 | 何时干（与账面正交） |
| **模型档** ★ | ✅ | strong｜缺省｜light｜— | 档位随任务复杂度（分层梯 L1/L2/L3） |
| **预算帽** ★ | ✅ | AUTO_BUDGET_LINE｜≤0.5 班｜数值 | 超帽宁停 |
| **skill_工具** ★ | ✅ | 可调用 skill 与工具白名单（逗号分隔·任务书可加严不可放宽） | 全窗=bash/fs 全套＋任务书指定 skill；轻窗=窄任务白名单（规则表/SOP 卡即技能）；核验岗=无额外 skill |
| **RAG 分配** ★ | ✅ | 可检索集合白名单（94-班外经验库/kb_search 集合名/—） | 检索域随岗位职责限定·防串域污染·省 token（kb_search 契约 ct-005·memory_source 先例 ⑦⑧） |
| station | 二选一 | pi 会话装载（无脚本消费面）｜脚本读卡路径 | pi 岗=无·本卡=规格视图 |
| prompt_source ★ | ✅ | 提示词唯一事实源指针（任务书模板/SOP 卡/SKILL.md） | 规格视图不复制提示词（拍板#211 先例） |
| trigger ★ | ✅ | 触发源（领单自动/拒领 jsonl/班末/手动按钮） | 修复岗列四源 |
| 三无边界 | 修复/轻窗岗必填 | 无领单权·无放行权·不翻格 | 施工窗写「有领单权（八闸绿后）」 |
| ctx_volume | 轻窗必填 | 窄盒注入清单 | 机械 grep 注入纪律 |
| 编制依据 | ✅ | 拍板号＋对比件路径 | 拍板行引对比件（P-X9） |

## §三·五 UI 前端自配置（五期候选·岗位配置面板）

**是什么**：每岗的 skill_工具/RAG 分配/模型档/预算帽 通过前台「岗位配置面板」可视化编辑——业主/主窗不改卡文件·面板改**岗位配置件.json**（运行态·每岗一份·默认值=岗卡正本）。

**沿既定模式**（#448③/#362 先例）：白名单（可配字段固化·越界 404）·令牌（x-admin-token·连错 5 次锁 60s）·审计（岗位配置审计.jsonl·per 岗 per 变更）·原子写（tmp+rename）＋写后复读·强确认（松化方向·沿 panic confirm 闸）。

**拍板点（五期票内）**：面板可配字段范围（推荐：skill_工具/RAG 分配/模型档/预算帽 四项可配·**车道/账面=拍板件不 UI 配**）·配置生效时机（下票生效·在飞窗不热改）。

**纪律**：改配置=岗位说明书变更——微调走 B 级留痕候追认·重大变更（如给核验员加工具）走拍板·岗卡正本同步更新。
