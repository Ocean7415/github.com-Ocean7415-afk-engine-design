# 闸口清单册 · 站3/4/5＋L2 派工链全闸口（≈41 闸·零 LLM 判据为绝对主体）

> **定位**：一条链的**完整闸口清单**（运行闸位参考表·逐闸：判据/LLM？/红绿权）——机制卡讲设计（为什么有这个闸），本册讲**闸位全量**（有哪些闸·判什么·谁能动红绿）。互链不复制。
> **红线总纲**：判卷零 LLM·闸口判据全部机械（exit code/哈希/计数/词面）·**唯一涉 LLM 闸＝对题审查员扣绿闸**——否决-only 设计（只能扣绿不能放行·判卷红绿权恒在 exit code）。
> **账面注记**：站3/4/5 闸＝包道工序票视角（L1）；L2 派工链闸＝窗票视角（直票道+任务包道下游）——双名制·同一工作的两个账面（拍板#534① 一链两账面）。

## §〇 闸口三定律（为什么闸口全部可信）

1. **判据机械**：exit code/sha 对拍/计数/词面——零 LLM 判卷（红线·LLM 永远无法把红变绿）；
2. **否决-only 例外**：对题审查扣绿闸（LLM 语义审查）设计为**只能扣绿不能放行**——LLM 有否决权无放行权；
3. **层层层拦截**：站3 拦「包对不对」·站4 拦「码对不对」·站5 拦「App 行不行」·L2 闸拦「票能不能派」——层层拦截坏货不下游。

## §五 统计与结论

| 维度 | 计数 |
|---|---|
| 总闸数 | **≈41**（站3 11＋站4 14＋站5 9＋L2 10·部分跨站复计） |
| 零 LLM 闸 | **39**（95%）——判据全部机械（exit code/sha/ajv/计数/词面） |
| 涉 LLM 闸 | **2**——对题审查扣绿闸（**否决-only**）＋会审门（LLM 辅助检查·红绿权仍在 exit code） |
| 红绿权终局 | 验收命令 exit code（站5/复考）＋**业主**（终认/追认/翻案）——判卷零 LLM 红线全链贯通 |

**结论一句话**：41 闸里 39 个零 LLM·2 个 LLM 闸全是「否决-only」（无放行权）——**这条链上没有任何一个 LLM 能把红变绿**。这就是「降低幻觉」初心的机械化身：幻觉可以出现在生成侧（岗），但**过不了闸**（判卷零 LLM）。
