§0 一句话

节点详注表（图正下方·每节点做什么/边界/锚点）：

节点详注
工单票施工输入：站3 导入后的票（含计划/预算/验收命令）——站4 只按工单施工，不自造票不出题（出题权冻结在开工前）。
自动分槽auto=业主拍板默认档：前端票走确定性保底，其余走 LLM——分槽规则机械可预期，机器不发明新档位。
copy 槽确定性施工员：搬运 artifacts 保底（基线/前端票），零 LLM 零漂移——降级链的落点与确定性路线的本体。
llm 槽写码工程师：五槽装备+设计书全文→分文件生成→反馈式自愈环（⟲≤3）——产能担当，预算走工单 llm-call-budget。
runAcceptanceGuarded判卷守卫（拍板#82·锚 ts/src/station4-build/build.ts:210）：判卷前校验工作区副本哈希——防「先改判卷素材再跑命令」的作弊面；红绿权仍归验收命令本身。
篡改红旗fail-closed 终局：不进⟲环不进降级链、不可自愈豁免——守卫是唯一「一票终局」路径，因它防的是对判卷制度本身的攻击。
降级切 copy预授权降档：⟲3 不绿且有素材→自动切 copy+DEC 留痕晨报追认——降级可追认可推翻，不静默吞结果。
